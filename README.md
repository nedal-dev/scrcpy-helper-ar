# scrcpy-helper-ar

مساعد عربي مجاني لتشغيل [scrcpy](https://github.com/Genymobile/scrcpy) على أندرويد من دون حفظ أوامر طويلة. يفحص وجود الأدوات وحالة اتصال الهاتف، ثم يعرض أوضاعًا جاهزة للأداء والجودة والعروض والتسجيل.

> المشروع غير رسمي ولا يتبع فريق scrcpy. جميع الملفات مفتوحة المصدر، ولا تجمع الأداة أي بيانات أو ترسلها إلى خادم.

## ما الذي يقدمه المشروع؟

- سكربت تفاعلي لويندوز: `scrcpy-helper.bat`.
- سكربت تفاعلي للينكس وماك: `scrcpy-helper.sh`.
- [مولّد أوامر scrcpy عربي](https://nedal-dev.github.io/scrcpy-helper-ar/) يعمل داخل المتصفح.
- تشخيص واضح لحالات `unauthorized` و`offline` وعدم ظهور الهاتف.
- تقرير تشخيصي محلي لا يتضمن الرقم التسلسلي للهاتف.

## المتطلبات

1. هاتف أندرويد مع تفعيل **USB Debugging**.
2. تثبيت [scrcpy من المصدر الرسمي](https://github.com/Genymobile/scrcpy/releases).
3. توفر `ADB` و`scrcpy` في المجلد الحالي أو ضمن `PATH`.

نسخة ويندوز الرسمية من scrcpy تتضمن الملفات اللازمة عادة. ضع `scrcpy-helper.bat` داخل مجلد scrcpy بعد فك الضغط لتشغيله بسهولة.

## التشغيل على ويندوز

1. نزّل `scrcpy-helper.bat` وضعه داخل مجلد scrcpy.
2. صِل الهاتف بكابل بيانات وافتح قفله.
3. وافق على رسالة السماح بتصحيح USB في الهاتف.
4. شغّل `scrcpy-helper.bat` واختر الوضع المناسب.

## التشغيل على لينكس وماك

بعد تثبيت `ADB` و`scrcpy`، امنح الملف صلاحية التشغيل ثم شغّله:

```bash
chmod +x scrcpy-helper.sh
./scrcpy-helper.sh
```

## أوضاع التشغيل

| الوضع | الإعدادات الأساسية | الاستخدام المقترح |
|---|---|---|
| متوازن | 1080، 30FPS، إطفاء شاشة الهاتف | الاستخدام اليومي |
| أسرع أداء | 720، 30FPS، من دون صوت | الكمبيوتر الضعيف أو التقطيع |
| جودة عالية | 1920، 60FPS، 16Mbps | النصوص والصورة الواضحة |
| عرض تقديمي | ملء الشاشة وإبقاء الهاتف نشطًا | الشرح والاجتماعات |
| تسجيل | فيديو MKV مع الصوت عند دعمه | تسجيل الشروحات |
| افتراضي | إعدادات scrcpy الأصلية | الاختبار وحل المشكلات |

قد لا يصل الهاتف فعليًا إلى معدل الإطارات المحدد؛ يعتمد ذلك على الجهاز والمحتوى والترميز.

## حل سريع للمشكلات

- **unauthorized:** افتح الهاتف ووافق على رسالة تصحيح USB، ثم أعد تشغيل السكربت.
- **offline:** افصل الكابل، أوقف تصحيح USB وشغّله مجددًا، ثم أعد الاتصال.
- **لا يوجد جهاز:** جرّب كابل بيانات ومنفذ USB آخر واختر وضع نقل الملفات.
- **ADB أو scrcpy غير موجود:** ضع السكربت داخل مجلد scrcpy الرسمي أو أضف الأدوات إلى `PATH`.

لشرح أوسع ومقارنة البدائل، اقرأ مقال إدراك: [أفضل 4 طرق لعرض شاشة الجوال على الكمبيوتر عن طريق USB](https://idraaak.com/%d8%a7%d8%b8%d9%87%d8%a7%d8%b1-%d8%b4%d8%a7%d8%b4%d8%a9-%d8%a7%d9%84%d9%87%d8%a7%d8%aa%d9%81-%d8%b9%d9%84%d9%89-%d8%a7%d9%84%d9%83%d9%85%d8%a8%d9%8a%d9%88%d8%aa%d8%b1/).
